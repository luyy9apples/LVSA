01 / The question

One variable.
Many constraints.

In a complex knowledge graph query, an existential variable can connect several atomic constraints. Every occurrence must refer to a compatible latent witness.

GroundingFaithful, but costly

Enumerates candidate entities to maintain logical equivalence.

Latent SkolemizationEfficient, but vulnerable

Can entangle shared variables in a single query representation.

LVSA constructs a persistent latent state for each existential variable and reuses it across its connected constraints.

02 / The method

A structured path
through the query.

LVSA reasons in topological order, composing relational constraints while retaining the identity of each existential variable.

01

Bind

Vector-symbolic operations combine entity and relation embeddings into atomic constraints.

02

Skolemize

A differentiable module builds a constraint-conditioned state for each existential variable.

03

Preserve logic

A logic-regularized neural negator handles hard negation and supports consistent composition.

03 / Evidence

Stronger answers,
consistent reasoning.
