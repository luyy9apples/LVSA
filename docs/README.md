# GitHub Pages publishing

This directory is the standalone project website for LVSA. It uses plain HTML, CSS, and a small JavaScript enhancement; no build step is needed.

After the changes are pushed to the repository's `main` branch, open **Settings → Pages** on GitHub. Under **Build and deployment**, select **Deploy from a branch**, then choose **main** and **/docs**. The site URL will be `https://luyy9apples.github.io/LVSA/` once GitHub finishes publishing.

The `LVSA_CIKM2026.pdf` file is the current author manuscript. Replace it here if a final publisher PDF or updated accepted manuscript becomes available.
